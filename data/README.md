# data/

- `orthologs_1to1.csv`: 17,609 one-to-one mouse-human ortholog pairs derived from MGI's `HOM_MouseHumanSequence.rpt` (downloaded 2026-09-01) by `code/00_orthologs.py`. This is the exact table used in the paper.
- `raw/` (git-ignored): the Chen et al. 2021 Slide-seqV2 pucks, fetched by `code/00_download.sh`.
